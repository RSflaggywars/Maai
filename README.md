# AI-Lab

Make AIs with **Python and C**. Python trains the brain, C runs it.

The system: a tiny neural network (2 inputs -> 8 hidden -> 1 output) is
trained in Python with numpy, its weights are exported to a plain-text
`weights.txt`, and a compiled C program loads those weights and makes
predictions — no Python needed at runtime, no libraries needed at all.

## Layout

```
AI-Lab/
  python/train.py    trains the net, writes weights.txt
  c/predict.c        loads weights.txt, runs predictions
  c/build.bat        compiles predict.exe (needs gcc)
  weights.txt        generated by train.py
```

## Quick start

```sh
# 1. train (needs python + numpy)
cd python
python train.py

# 2. build the C predictor (needs gcc)
cd ..\c
build.bat          # or: gcc -O2 -o predict.exe predict.c -lm

# 3. run it
predict.exe                # interactive mode
predict.exe 0 1            # one-shot: prints the output
```

## What it learned

The net is trained on **XOR** — the classic proof that a neural network
can learn a non-trivial function:

```
0 XOR 0 = 0  ->  ~0.03
0 XOR 1 = 1  ->  ~0.97
1 XOR 0 = 1  ->  ~0.97
1 XOR 1 = 0  ->  ~0.03
```

## Make your own AI

- **Change what it learns**: edit the `X`/`Y` arrays in `python/train.py`
  (any inputs/outputs you want — keep input count = 2 for now, or update
  `MAX_IN`/`MAX_HIDDEN` in predict.c for bigger nets).
- **Bigger network**: raise `HIDDEN` in train.py and `MAX_HIDDEN` in
  predict.c together.
- **More layers**: extend train.py's forward/backward and predict.c's
  `predict()` — the weights file format already supports it if you add
  more weight blocks.

## Requirements

- Python 3.8+ with numpy (`pip install numpy`)
- gcc (e.g. [MinGW](https://winlibs.com) or `winget install mingw`)
